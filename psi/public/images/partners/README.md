# Partnerlogoer

Bare offisielle logofiler, hentet fra organisasjonens egne sider. Ikke
omtegn, ikke fargelegg, ikke strekk. Legg fila her og sett `logo` på
partneren i `src/data/psi.js`, f.eks. `logo: '/images/partners/ssn.svg'`.
Mangler fila, viser siden navnet som tekst.

| Partner | Hent fra |
|---|---|
| SiG | https://www.sig.no/ |
| SSN | https://www.ssn.no/ |
| USN | https://www.usn.no/om-usn/presserom/logo-design-og-grafiske-elementer/ (følg USNs regler) |
| BEHA Sport | https://behasport.no/ eller be BEHA om fil |
| Høyt Under Taket | https://hoytundertaket.no/ |
